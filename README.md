# 📌 Project Overview

**Super Store Sales Analytics** is an end-to-end Data Analytics and Machine Learning project that predicts retail sales and provides business insights through an interactive Power BI dashboard.

The project demonstrates the complete workflow from **data preprocessing**, **machine learning model development**, and **Flask deployment** to **interactive business intelligence reporting**.

---

# 🎯 Project Objectives

- Analyze retail sales data.
- Predict future sales using Machine Learning.
- Build a Flask-based prediction web application.
- Design an interactive Power BI dashboard.
- Generate actionable business insights using KPIs and visualizations.
